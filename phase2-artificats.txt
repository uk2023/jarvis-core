IMPORTANT FINDINGS
==================

1. Context carryover works for explicit stored project facts.

2. Correction carryover works.

3. Interruption recovery is NOT complete.
   "Continue from there" lost enough context to require
   the user to provide the previous material again.

4. Memory WRITE exists, but normal memory RETRIEVAL capability
   is missing from the conversational path.

5. Safe action execution + verification works.

6. Invalid action handling works without fabricated success.

7. Short-term task state survives an unrelated turn.

8. The B09 prompt only initiated a fallback test;
   it did not demonstrate an actual fallback event.

9. B10 demonstrated planning-worker invocation and a structured
   plan/execution/verification response, but not strong independent
   verification of a real task effect.

10. Existing 23/23 offline regression PASS must remain separate
    from this conversational baseline.
