PHASE 3 — FRUIT-FLY CONNECTOME EXPERIMENT
==========================================

STATUS: COMPLETE
Model type: Experimental computational model
Purpose: Validate a small connectome-derived neural subgraph as a
computational propagation + feedback substrate before Jarvis integration.

CONNECTOME
----------
Nodes: 32
Edges: 364

The full 166K+ neuron connectome was NOT copied into the simulator.
A small selected subgraph was used for controlled experimentation.

PHASE 3.1 — INITIAL DYNAMICS DIAGNOSTIC
----------------------------------------
The initial unnormalized dynamics showed severe numerical growth.

Observed mean activity:

step 0  = 0.03125
step 1  = 4.59375
step 2  = 181.188
step 3  = 6389.75
...
step 11 = 1.46006e16

Conclusion:
The original propagation operator was unstable for the selected
subgraph and could not be used directly for controlled feedback.

PHASE 3.2 — NORMALIZED OPERATOR
--------------------------------
Outgoing edge weights were normalized per source node.

The normalized operator produced bounded propagation.

Representative total activity:

step 0  = 1.0000
step 1  = 1.0000
step 2  = 0.9864
step 5  = 0.8996
step 10 = 0.7842
step 19 = 0.6173

All 32 nodes became active after propagation.

Simulator tests:
test_core.py
test_dynamics.py
test_normalized_operator.py

Result:
9 passed

PHASE 3.3 — ACTUATOR SWEEP
---------------------------
The actuator operating region was experimentally measured.

Representative steady-state behavior:

input 0.012 -> tail mean ~0.01626
input 0.014 -> tail mean ~0.01847
input 0.015 -> tail mean ~0.02013
input 0.016 -> tail mean ~0.02068
input 0.018 -> tail mean ~0.02289

This established an operating region around the target activity
of 0.020.

PHASE 3.4 — FEEDBACK ITERATIONS
--------------------------------
Multiple feedback-controller variants were tested.

V1/V2:
The original controller did not regulate the system effectively.

V3:
Bounded proportional seed feedback was introduced, but the system
settled far above the target.

V4:
Controller configuration resulted in no useful actuator correction.

V5:
Longer-horizon proportional control demonstrated convergence toward
the target region.

V6:
Deadband and bounded actuator behavior were introduced.

V7:
The controller was extended to 500 steps with a 50-step settling
window.
