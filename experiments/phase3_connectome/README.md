# JARVIS-NEURAL Phase 3 — Connectome Experiment

Goal:
Build a small computational neural circuit inspired by the public
Drosophila connectome.

Rules:
- Do not copy the whole fruit-fly brain.
- Do not modify the existing Jarvis Brain/Router/LLM path.
- Keep the experiment isolated.
- Preserve source neuron IDs and connection metadata where used.
- Measure state propagation and feedback.
- No functional improvement may be assumed.
- Phase 4 integration happens only after the standalone experiment works.

Dataset:
FlyWire public Drosophila connectome.

Initial experiment:
small selected subgraph -> computational neural circuit ->
activation propagation -> feedback/state measurement.
