# Phase 4 — Jarvis POC

Purpose:
Connect the Phase 3 experimental connectome to one limited Jarvis
workflow without replacing the existing Jarvis brain or LLM.

Rules:
1. Existing Jarvis brain remains authoritative.
2. Neural layer is experimental only.
3. Neural layer must be removable without breaking Jarvis.
4. Neural output must be observable.
5. No autonomous action execution is allowed from the neural layer.
6. Initial integration is state/feedback only.
7. Same input must be reproducible.
8. Phase 4 must produce measurable output for Phase 5 comparison.
