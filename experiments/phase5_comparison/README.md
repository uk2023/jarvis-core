# Phase 5 — Jarvis A/B Comparison

A = Current Jarvis
B = Current Jarvis + experimental neural layer

Rules:
1. Same test cases must be used for A and B.
2. Existing Jarvis brain remains authoritative.
3. Neural layer must not directly execute actions.
4. Measure only observable metrics.
5. No improvement may be claimed without measured evidence.
6. Record baseline before changing architecture.

Metrics:
- response latency
- context carryover
- interruption handling
- action success/failure
- state stability
- LLM calls
- token usage
- neural-layer overhead
